# Bảo Nam — Personal Archive

## Đưa web lên Internet để Google có thể tìm thấy

Cách dễ nhất là dùng GitHub Pages:

1. Tạo tài khoản GitHub.
2. Tạo repository mới, ví dụ `baonam-web`.
3. Upload `index.html`, `style.css`, `script.js`.
4. Vào **Settings → Pages**.
5. Chọn **Deploy from a branch → main → /(root)** rồi Save.
6. GitHub sẽ cấp cho bạn một địa chỉ dạng `https://TEN-GITHUB.github.io/baonam-web/`.
7. Trong `index.html`, sửa `canonical` từ `YOUR-USERNAME.github.io` thành địa chỉ thật của web.
8. Sau khi web chạy, có thể gửi URL cho Google Search Console để Google crawl/index trang.

Lưu ý: "có URL" và "được Google tìm thấy ngay" là hai việc khác nhau. Google cần thời gian để crawl và lập chỉ mục; không có cách đảm bảo xuất hiện ngay.
